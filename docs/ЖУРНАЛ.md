## 2026-10-15

- **Google Play, сборка 10319: два замечания.**
  - «Оптимизация DEX-кода ниже порога — обфускация 3 %», срок до февраля 2027. Включён R8 в релизе: `expo-build-properties` в app.json (`enableMinifyInReleaseBuilds`, `enableShrinkResourcesInReleaseBuilds`), то же вписано в android/gradle.properties. `bundleRelease` с R8 собирается (1 мин 24 с, app-release.aab 62 МБ, mapping.txt создан; предупреждения R8 — только про Amazon SDK из RevenueCat). Следующую Android-сборку проверить на устройстве: R8 может вырезать нужное (RevenueCat, Firebase).
  - «Неподдерживаемые API показа от края до края (Android 15)» — без срока. Вызовы `statusBarColor` / `navigationBarColor` / `LAYOUT_IN_DISPLAY_CUTOUT_MODE_*` — внутри самого React Native (`WindowUtil.kt`, `StatusBarModule.kt`), в нашем коде их нет; уйдёт с обновлением React Native.
- **Свайп: помутнение и анимация на JS.** На iPhone (20261015.1) анимации по-прежнему не было. Уходящая страница теперь мутнеет до 0,3 и отступает до 0,92, въезжающая проясняется; длительность 0,24 + 0,32 с. Анимация переведена с нативного драйвера на JS (`NATIVE = false` в useSectionSwipe, сдвиг окна в ZoomModal) — тот путь, что проверен: в безголовом Chrome (Playwright, свайп временно включён для веба) сняты кадры — сдвиг −140 px / прозрачность 0,75 посреди жеста, −390 px / 0,3 на выходе, новый раздел въезжает справа. На iPhone не проверено. Сборка 20261015.2.
- **Номера сборок с датой.** `npm run build:number` (`scripts/build-number.mjs`): iOS «1.3 (20261015.1)» — дата и какая сборка за день, Android 26101501; `-- --version 1.4` заодно меняет версию. Правит app.json, Info.plist, project.pbxproj, build.gradle. Текст в номер Apple не пускает — только числа через точку. Текущая сборка — 20261015.1; номер больше 10323, так что подходит, была 10323 залита или нет.
- **Свайп без анимации на iPhone (10322)** — разделы менялись, а экран не двигался. Причина: слой-обёртка без фона и со сдвигом 0 новая архитектура React Native выбрасывает из нативного дерева (ViewShadowNode: identity transform не образует вида), и анимировать было нечего. Лечение — `collapsable={false}` на слое свайпа в App.tsx и в ZoomModal. Сборка 10323. На устройстве не проверено.

  - Дневная беседа списывается не по нажатию кнопки, а на первом ответе Poly человеку (`sessionAnswered`): обрыв на старте больше не съедает беседу на весь день.
  - Жалоба «нажал — что-то прервалось — всё»: по логам Cloud Run 2026-10-14 с сервера ни одной ошибки и ни одного 402; из браузера пришли только `/tier`, запросов распознавания, Claude и озвучки не было — беседа рвалась в браузере до первого запроса (запись с микрофона или местная проверка объёма). Причина не установлена — нужен текст ошибки.
- **Клавиатура без подсказок в ответах.** Ученик печатает только в «Письме» и в ответах «Слушания» — там `NO_SUGGESTIONS` стоял с 2026-10-01 (`852f02e`, вошёл в сборку 10321), но на iOS выключал лишь автоисправление и подчёркивание. Экзамен устный, тест слов и пропуски — выбор кнопками, полей ввода там нет.
  - `NO_SUGGESTIONS`: + `autoCapitalize: 'none'` (заглавную ученик ставит сам), `textContentType: 'none'`.
  - `plugins/withPlainKeyboard.js` (в app.json, применён к ios/AppDelegate.swift): поле с `autoCorrect={false}` при фокусе теряет дописывание серым (iOS 17+), «умные» кавычки и тире, Writing Tools (iOS 18+). Swift проверен компилятором отдельно; нужна новая нативная сборка.
  - Android: `autoCorrect={false}` ставит флаг NO_SUGGESTIONS — Gboard его слушается, клавиатура Samsung может игнорировать.
- **Навигация свайпами** (мобильное приложение; в браузере по-прежнему домик). Два уровня:
  - раздел открыт вглубь — свайп вправо возвращает на его верхний уровень: урок → программа грамматики, карточки/повторение/тест → список слов, беседа/разбор экзамена → темы, тест уровня → «Сегодня»; окна поверх (архив, задание, урок из тетради, профиль, аккаунт) закрываются свайпом вправо;
  - верхний уровень — свайп листает разделы в порядке меню (влево — следующий, вправо — предыдущий), без перехода по кругу; на краю экран тянется туго и возвращается.
  - Экран идёт за пальцем, после порога (¼ ширины или быстрый взмах) уезжает, новый въезжает с другой стороны.
  - Не листается: во время беседы, ответа на экзамене, разговора в тесте уровня, при открытом меню или экране покупки.
  - `src/hooks/useSectionSwipe.ts` (жест, `useSwipeBack` для разделов), `App.tsx`, `ZoomModal.tsx`, `ScreenMenu.tsx` (`SCREENS`), разделы грамматики, слов, экзамена, теста уровня.
  - Проверена только типизация; на устройстве не проверено. Смотреть: горизонтальная таблица в уроке и карусель языков в настройках должны листаться сами, а не менять раздел.

- **Пункт 6, скорость голоса.** Причина паузы: ход беседы ждал весь ответ Claude — реплику *и* разбор ошибок, — и только потом шёл в озвучку. Теперь ответ идёт потоком, поля переставлены (реплика → прощание → разбор), озвучка стартует, как только готова реплика; разбор ложится под фразу человека позже. Чем больше ошибок в фразе, тем больше выигрыш.
  - `functions/src/index.ts` — прокси пропускает поток Claude и считает расход по событиям потока.
  - `src/services/llm.ts` — `respond` с `onReply`; на старом прокси или без потокового fetch откатывается на прежний целый ответ.
  - `src/hooks/useConversation.ts` — реплика отдаётся голосу сразу, разбор дописывается следом.
  - Экзамен и тест уровня не тронуты. Не измерено на устройстве.
  - Отложено (следующие шаги по скорости, если понадобится): потоковая озвучка, `minInstances: 1` против холодного старта (стоит денег), кэш тарифа/расхода на сервере.
