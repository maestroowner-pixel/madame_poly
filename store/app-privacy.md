# Ответы на анкету App Privacy

Apple спрашивает не про «храните ли вы данные», а про то, что покидает
устройство. У Madame Poly покидает: звук реплики, текст беседы, анонимный
идентификатор со счётчиком месячного расхода, состояние подписки и — только у
вошедших — учебные данные. Все запросы к OpenAI и Anthropic идут через наш
сервер-посредник (функция `api` в Firebase, europe-west1); он не хранит ни
записей, ни текстов.

## Data Not Collected?
Нет. Приложение передаёт данные третьим сторонам для работы функций, поэтому
вариант «Data Not Collected» не подходит.

## Contact Info → Email Address
- Собирается: **да**, но только если человек завёл аккаунт.
- Связано с личностью: **да** (это и есть идентификатор аккаунта).
- Используется для отслеживания: **нет**.
- Цели: **App Functionality** (вход и синхронизация между устройствами).

## User Content → Audio Data
- Собирается: **да**.
- Связано с личностью: **нет** (запись уходит на распознавание без имени;
  посредник проверяет по идентификатору только объём и саму запись не
  хранит).
- Используется для отслеживания: **нет**.
- Цели: **App Functionality** (распознавание речи и озвучка ответа).

## User Content → Other User Content
- Собирается: **да** — текст беседы, исправления, упражнения, результаты
  аудирования.
- Связано с личностью: **да, если выполнен вход** (тогда данные лежат в
  Firestore под идентификатором аккаунта); без аккаунта — не связано.
- Используется для отслеживания: **нет**.
- Цели: **App Functionality**.

## Identifiers → User ID
- Собирается: **да**, у всех — идентификатор Firebase Auth. Без аккаунта он
  анонимный (случайный, без имени и почты), с аккаунтом — идентификатор
  аккаунта. По нему посредник считает месячный объём, а RevenueCat хранит
  подписку.
- Связано с личностью: **да** (у вошедших — с почтой). Отслеживание: **нет**.
- Цели: **App Functionality**.

## Purchases → Purchase History
- Собирается: **да** — состояние подписки (Pro или Max), через RevenueCat.
- Связано с личностью: **да** (по идентификатору). Отслеживание: **нет**.
- Цели: **App Functionality** (открыть тариф на всех устройствах).

## Usage Data → Other Usage Data
- Собирается: **да** — сумма месячного расхода API по идентификатору
  (Firestore `spend/{uid}`), чтобы держать объём тарифа.
- Связано с личностью: **да** (по идентификатору). Отслеживание: **нет**.
- Цели: **App Functionality**.

## Чего НЕ собираем — во всех разделах отвечать «нет»
Location · Contacts · Health & Fitness · Financial Info · Browsing History ·
Search History · Product Interaction · Diagnostics · Advertising Data ·
Sensitive Info · Photos (фото аватарки не покидает устройство — синхронизация
уносит только путь к файлу).

## Tracking
На вопрос «Do you use data for tracking?» — **нет**. Рекламных
идентификаторов, сторонней аналитики и трекеров в приложении нет, поэтому
разрешение ATT не запрашивается.

## Третьи стороны, которые стоит назвать в описании обработки
- **OpenAI** — распознавание речи (Whisper) и озвучка (TTS).
- **Anthropic** — ответы собеседницы, разбор ошибок, упражнения, диктанты.
- **Google Firebase** — сервер-посредник (Cloud Functions), анонимный вход и
  счётчик расхода у всех; вход по почте и хранение учебных данных — только у
  тех, кто завёл аккаунт.
- **RevenueCat** — состояние подписки по идентификатору; платёжных данных не
  получает.

OpenAI и Anthropic не обучают на этом модели (условия API) и могут хранить
запросы до 30 дней для контроля злоупотреблений. Ни один из сервисов не
получает от нас рекламных или аналитических данных.

## Account deletion (обязательное требование Apple)
В приложении есть вход, поэтому Apple требует способ удалить аккаунт. Сейчас
удаление идёт письмом на kukalab@icloud.com — это допустимо, но при проверке
могут попросить кнопку в самом приложении. Если рецензент придерётся, добавим
её в экран аккаунта: вызов deleteUser у Firebase плюс удаление поддерева
users/{uid} в Firestore.
